Projets

Projets académiques & personnels

Six réalisations qui couvrent l'algorithmique, le développement web, l'administration réseau et système, la sécurité d'accès et l'analyse de données.

01 / 06
Algorithmique

Moteur de routage réseau basé sur tables de hachage

Moteur de recherche de routes écrit en C, fondé sur des tables de hachage avec gestion des collisions. Il permet d'insérer, de supprimer et de retrouver une route en temps quasi constant, grâce à des structures de données dynamiques, une manipulation des pointeurs et une allocation mémoire maîtrisées.

Contexte

Algorithmique et structures de données : réduire les temps d'accès lors de la recherche de routes réseau.

Réalisations

  • Table de hachage avec gestion des collisions, insertion, suppression et recherche en temps quasi constant.
  • Structures de données dynamiques, pointeurs, allocation mémoire et optimisation algorithmique.
  • C
  • Structures de données
  • Algorithmes
02 / 06
Développement web

Plateforme web de gestion de location de véhicules

Application web full-stack pour gérer les réservations, les clients, les véhicules, les contrats et les disponibilités liés à la location de véhicules. Elle repose sur une architecture MVC en PHP, une base MySQL normalisée conçue avec Merise, l'authentification des utilisateurs et une interface responsive.

Contexte

Centraliser dans une seule application la gestion d'une activité de location de véhicules.

Réalisations

  • Gestion des réservations, des clients, des véhicules, des contrats et des disponibilités.
  • Base de données relationnelle normalisée (Merise), authentification, interface responsive et architecture MVC.
  • PHP
  • MySQL
  • HTML5
  • CSS3
  • JavaScript
  • MVC
03 / 06
Réseaux & systèmes

Déploiement d'une infrastructure réseau sécurisée

Mise en place sous Linux d'une infrastructure de services réseau : serveur web Apache, DNS, DHCP, FTP, Samba et NFS. Le projet couvre l'administration système, la configuration de chaque service, la gestion des utilisateurs, l'automatisation par scripts Bash et la sécurisation des accès.

Contexte

Administration système Linux : faire fonctionner ensemble les services réseau d'une infrastructure.

Réalisations

  • Serveur web Apache, DNS, DHCP, FTP, Samba et NFS configurés sous Linux.
  • Gestion des utilisateurs, automatisation Bash et sécurisation des accès.
  • Linux
  • Apache
  • Bash
  • DHCP
  • DNS
  • FTP
  • Samba
  • NFS
04 / 06
Réseaux & sécurité

Portail captif Wi-Fi avec authentification centralisée

Portail captif Wi-Fi qui associe pfSense, pour le contrôle d'accès au réseau, et FreeRADIUS, pour l'authentification centralisée des utilisateurs. Une interface d'administration gère les comptes, les statistiques de connexion, la journalisation et les règles de pare-feu, sur une infrastructure virtualisée.

Contexte

Contrôler l'accès à un réseau Wi-Fi et authentifier les utilisateurs depuis un point central.

Réalisations

  • Intégration de FreeRADIUS pour l'authentification et de pfSense pour le contrôle d'accès.
  • Interface d'administration : comptes, statistiques, journalisation, règles de pare-feu, virtualisation.
  • pfSense
  • FreeRADIUS
  • Flask
  • MySQL
  • VMware
05 / 06
Données

Analyse décisionnelle de données d'entreprise

Analyse de jeux de données d'entreprise volumineux : nettoyage, transformation et exploration avec Pandas et NumPy dans Jupyter. Le projet produit des tableaux de bord, des indicateurs statistiques et des visualisations Matplotlib, puis en tire des recommandations fondées sur les données.

Contexte

Transformer des données brutes d'entreprise en informations utiles à la prise de décision.

Réalisations

  • Nettoyage, transformation et analyse de jeux de données volumineux.
  • Tableaux de bord, indicateurs statistiques, visualisations et recommandations.
  • Python
  • Pandas
  • NumPy
  • Matplotlib
  • Jupyter
06 / 06
Réseaux & systèmes

Mise en place d'un système de communication unifiée

Infrastructure de communication unifiée sous Linux : téléphonie IP avec Asterisk (SIP), messagerie instantanée avec Prosody (XMPP) et courrier électronique avec Postfix et Dovecot. Les comptes et clients sont configurés puis validés par des tests d'appels, de messages instantanés et d'envoi de courriels.

Contexte

Réunir téléphonie IP, messagerie instantanée et courrier électronique sur une même infrastructure.

Réalisations

  • Téléphonie IP (Asterisk, SIP), messagerie XMPP (Prosody), courriel (Postfix, Dovecot).
  • Configuration des comptes SIP et des clients, tests d'appels, d'échanges et de courriels.
  • Linux
  • Asterisk
  • XMPP
  • Dovecot
  • Prosody
  • Postfix
  • SIP
